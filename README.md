# Customer-Trend-Behaviour
# Data Analytics Project

## Overview

This project demonstrates a complete end-to-end data analytics workflow, from data collection and preprocessing to analysis and visualization. The objective is to transform raw data into meaningful insights using Python, SQL, and Power BI while following a structured analytics process.

---

## Dataset

* **Source:** Publicly available dataset
* **Format:** CSV
* **Description:** The dataset contains structured records that were analyzed to identify trends, patterns, and key performance metrics.

---

## Tools & Technologies

* **Python** – Data loading, cleaning, and Exploratory Data Analysis (EDA)
* **Pandas & NumPy** – Data manipulation and preprocessing
* **Matplotlib & Seaborn** – Data visualization
* **PostgreSQL / MySQL / SQL Server** – SQL querying and data analysis
* **Power BI** – Interactive dashboard creation
* **Microsoft PowerPoint** – Presentation of findings
* **Canva** – Report and presentation design

---

## Project Steps

### 1. Data Loading

* Imported the dataset into Python.
* Examined the structure and data types.

### 2. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent formatting.
* Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)

* Generated descriptive statistics.
* Identified trends, distributions, and relationships.
* Created visualizations to support findings.

### 4. SQL Analysis

* Imported the cleaned dataset into PostgreSQL, MySQL, or SQL Server.
* Wrote SQL queries using:

  * SELECT
  * WHERE
  * GROUP BY
  * ORDER BY
  * JOIN
  * Aggregate functions
* Extracted business insights from the data.

### 5. Dashboard Development

* Built an interactive Power BI dashboard.
* Added charts, KPIs, filters, and slicers for better data exploration.

### 6. Reporting

* Summarized key findings in a professional report.
* Prepared a presentation highlighting the analysis, methodology, and insights.

---

## Results

The analysis helped identify important trends and patterns within the dataset. Interactive dashboards and SQL-based insights enabled better understanding of key metrics and supported data-driven decision-making.

## How to Run

1. Clone the repository.
2. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
3. Open the Jupyter Notebook files and execute the Python scripts.
4. Import the cleaned dataset into PostgreSQL, MySQL, or SQL Server and run the SQL queries.
5. Open the Power BI dashboard (`.pbix`) to explore the visualizations.
6. Review the project report and presentation for a summary of the findings.
